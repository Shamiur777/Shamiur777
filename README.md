# Hi, I'm Shamiur Rahman

Co-founder and Managing Director of **HulkenStein**, an EdTech group in Bangladesh with 200+ people serving 1M+ students. BSc Biomedical Engineering, BUET.

I find bottlenecks in real operations, then build and deploy AI systems to fix them. My in-house accounting system handles 600–700 transactions a month and replaced software that would cost BDT 17,000–20,000 a month. Those systems hold company data, so the projects below recreate the same ideas with synthetic data. Every README states what was measured, what was simulated and what is not done yet.
